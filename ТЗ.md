# Unified Agricultural Production Platform (Agro ERP)

## Полное техническое задание

---

# 1. Общая концепция системы

## Цель системы

Создать единую ERP/Operations Platform для:

* открытого грунта,
* теплиц,
* nursery,
* гидропоники,
* аэропоники,
* вертикальных ферм,
* контейнерного выращивания,
* smart farming,
* IoT/automation,
* production planning,
* agronomy analytics.

Система должна одинаково эффективно работать:

* для маленького огорода,
* фермерского хозяйства,
* промышленной теплицы,
* hydro/aero farm,
* vertical farm,
* multi-location агрохолдинга.

---

# 2. Архитектурная парадигма

## Основные принципы

### Domain-Driven Design (DDD)

Система строится на bounded contexts.

---

### Event-driven architecture

Система хранит:

* не только текущее состояние,
* но и timeline событий.

---

### Capability-driven production model

Система НЕ делится на:

* hydro module,
* greenhouse module,
* field module.

Вместо этого используются:

* Production Units,
* Capabilities,
* Sensors,
* Automation.

---

### Unified Production Topology

Любой объект выращивания является:

```
ProductionUnit
```

Примеры:

* поле,
* грядка,
* NFT канал,
* горшок,
* rack,
* shelf,
* vertical tower,
* теплица,
* reservoir.

---

# 3. Bounded Contexts

Система состоит из следующих bounded contexts:

1. Spatial Context
2. Production Context
3. Agronomy Context
4. Planning Context
5. Operations Context

# 4. Spatial Context

## Назначение

Хранение:

* геометрии,
* топологии,
* layout,
* иерархии production units,
* пространственных отношений.

Spatial Context НЕ хранит:

* агрономию,
* посадки,
* операции,
* inventory.
