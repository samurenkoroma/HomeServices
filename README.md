# Home Services — Умная ферма / Тепличное хозяйство

Бэкенд для управления полями, культурами, планами посадок, циклами выращивания и задачами ухода.

## Стек
- Go 1.25
- Fiber + JWT
- Postgres + GORM (миграции)
- DDD + CQRS + Domain Events

## Запуск
```bash
cp .env.example .env
docker compose up -d db
go run ./cmd/server
```

7. Схема полного процесса
   text

1. Farm (создание объекта)
   ├── Создать поле/теплицу
   └── Добавить геометрию (не доделано) 🔴
   │
   ▼
2. Growing (настройка места)
   ├── Создать сезон
   ├── Настроить место на сезон
   └── Выбрать тип использования (монокультура/поликультура)
   │
   ▼
3. Crop (создание плана)
   ├── Создать тип культуры
   ├── Создать сорт (опционально)
   ├── Создать план
   ├── Добавить этапы (не доделана валидация) 🟡
   ├── Добавить правила севооборота
   └── Опубликовать план
   │
   ▼
4. Growing (начало цикла)
   ├── Выбрать место (из настроенных)
   ├── Выбрать активный сезон
   ├── Выбрать опубликованный план
   └── Начать цикл
   │
   ▼
5. Growing (управление циклом)
   ├── Записывать операции
   ├── Фиксировать урожай
   └── Завершить цикл

8. Приоритетные задачи

   Загрузка реальных объектов Farm в ConfigureAreaForm — сейчас заглушка

   Загрузка реальных данных в StartCycleForm — сейчас заглушка
